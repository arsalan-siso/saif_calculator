آلة حاسبة بواجهة رسومية مبنية بلغة البرمجة العربية **سيف (Saif)** باستخدام مكتبات SDL2.

## 📸 لقطة الشاشة

![آلة حاسبة سيف](screenshot.png)

---

## ✨ الميزات

- ✅ **واجهة رسومية** مبنية على SDL2
- ✅ **أزرار تفاعلية** مع دعم الفأرة
- ✅ **عمليات حسابية** أساسية (جمع، طرح، ضرب، قسمة)
- ✅ **دعم الأعداد العشرية** (الفاصلة)
- ✅ **زر المسح** (C) لتصفية الشاشة
- ✅ **عرض النتائج** بشكل فوري
- ✅ **خط عربي** جميل للأرقام والرموز
- ✅ **صغير الحجم** وسريع الأداء

---

## 🛠️ المتطلبات

- نظام Linux (تم اختباره على Kali/Ubuntu/Debian)
- مكتبات SDL2:
  ```bash
  sudo apt install gcc libsdl2-dev libsdl2-mixer-dev libsdl2-ttf-dev
